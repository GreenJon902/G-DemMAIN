# Environment variables
This folder stores the namaes and documentation of the environment variables.

`common` - General settings that can be accessible to anyone.
`g_mc_g_web_minecraft` - Minecraft specific configurations which should be exposed to the g\_mc and g\_web daemons.
`g_mc_g_discord_minecraft` - Minecraft specific configurations which should be exposed to the g\_mc and g\_discord daemons.
`g_mc_minecraft` - Minecraft specific configurations which should only be viewed by g_mc (e.g. database keys).
`g_web_website` - Settings for the website that should only be viewed by g_web.
`g_discord_bot` - Settings for the Discord bot that should only be viewed by g_discord.
